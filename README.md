# منصة مستر عادل عزت — للغة الإنجليزية

منصة تعليمية بسيطة وقوية بتربط المستر بطلابه: شرح، امتحانات وكويزات بتصحيح آلي، سجل حضور ودرجات، ومنتدى للطلاب — والدخول **بأكواد محددة** بس، مفيش تسجيل مفتوح.

## التشغيل

الموقع عبارة عن صفحة ثابتة (Static) — أي سيرفر ثابت يكفي:

```bash
python3 -m http.server 8080
# أو
npx serve .
```

وافتح `http://localhost:8080`.

## طريقة الاستخدام (للمستر)

1. **ادخل للوحة التحكم**: من صفحة الدخول اضغط «دخول المستر».
   - كلمة السر الافتراضية: `adel2026` — **غيّرها فوراً** من قسم «الإعدادات» جوه اللوحة.
2. **أضف الطلاب**: في قسم «الطلاب والأكواد» اكتب اسم الطالب وفصله واضغط «إضافة طالب وتوليد كود» — هيظهرلك كود زي `ADEL-3A-K7M2`.
   - اضغط على الكود لنسخه، أو ابعت فوراً لولي الأمر على واتساب (لو كتبت رقم الموبايل مع إضافة الطالب).
3. **الحضور**: في قسم «الحضور» اختر تاريخ الحصة (والفصل لو حبيت) واضغط «فتح كشف الحضور» وحدد حاضر/غائب لكل طالب.
4. **الامتحانات والكويزات**: أنشئ امتحان جديد، ضيف أسئلة اختيار من متعدد وحدد الإجابة الصحيحة — التصحيح آلي والدرجة بتتسجل تلقائياً.
5. **الشروحات**: ضيف درس بشرح مكتوب + روابط فيديوهات يوتيوب (كل رابط في سطر) — الطالب بيشوفهم جوه المنصة.
6. **المنتدى**: تقدر تراقب مواضيع الطلاب وتحذف أي موضوع مش مناسب.
7. **نسخة احتياطية**: اضغط «تنزيل نسخة JSON» من وقت لآخر، وتقدر تستوردها في أي وقت.

## طريقة الاستخدام (للطالب)

1. يفتح الموقع ويكتب **الكود** اللي المستر حددهوله.
2. يتفتحله كورس فصله: الشروحات والفيديوهات، الامتحانات، والمنتدى.
3. بعد ما يحل أي امتحان يشوف درجته والإجابات الصحيحة فوراً، وسجل حضوره ودرجاته في «ملفي».

## البيانات

- كل البيانات بتتخزن في **مستند واحد** على Firebase Firestore (نفس مشروع الموقع القديم) في المسار `academy/adelEzzat` — فأي طالب يفتح من أي جهاز هيشوف نفس البيانات.
- لو Firebase مش متاح لأي سبب، المنصة بتشتغل في **وضع محلي** على المتصفح (localStorage) عشان ما تقفش، بس في الحالة دي البيانات بتاعت الجهاز ده بس — فعّل الإنترنت أو اتأكد من إعدادات المشروع.
- المشروع الحالي مستخدم بجانب بيانات عيادة قديمة؟ لأ — العيادة القديمة اتنقلت لمجلد `clinic-old/` لو احتجتها، وقاعدة البيانات بتاعة المنصة **مستند منفصل تماماً**.

### قواعد أمان Firestore (firestore.rules)

المنصة بتقرأ وتكتب من المتصفح مباشرة بدون تسجيل دخول Firebase، عشان كده القواعد في ملف `firestore.rules` بتسمح بالوصول **لمستند المنصة ومستند العيادة بس**، وتمنع أي مسار تاني نهائياً.

عشان تطبق القواعد — اختار طريقة:

**من Firebase Console (أسرع حل):**
1. افتح [console.firebase.google.com](https://console.firebase.google.com) → مشروع `clinic-nour`
2. Build → **Firestore Database** → تبويب **Rules**
3. انسخ محتوى ملف `firestore.rules` والصقه بدل الموجود، واضغط **Publish**

**من Firebase CLI:**
```bash
npm install -g firebase-tools
firebase login
firebase deploy --only firestore:rules   # بستخدم ملف firebase.json الجاهز
```

> ⚠ **ملحوظة أمان**: القواعد دي بتسمح لأي حد يعرف رابط الموقع يقرأ ويعدل بيانات المنصة (زي نمط العيادة القديم بالظبط) — مناسب لفصل صغير. لو حبيت تقوّيها، في نسخة جاهزة بـ Anonymous Authentication مشروحة جوه ملف `firestore.rules` نفسه.

## الأمان — ملاحظات مهمة

- أكواد الطلاب وكلمة سر اللوحة بيتخزنوا في قاعدة البيانات وتتحدث من المتصفح مباشرة؛ ده مناسب للفصول الصغيرة والاستخدام العائلي، لكنه مش نظام مصادقة كامل.
- قواعد Firestore في `firestore.rules` بتقفل كل المسارات ما عدا مستند المنصة والعيادة — راجع قسم «قواعد أمان Firestore» فوق لخطوات النشر.
- **غيّر كلمة السر الافتراضية** من قسم الإعدادات أول ما تفتح اللوحة.
- لو حبيت ترقّي الحماية بعدين: Firebase Authentication (النسخة المشروحة في ملف القواعد) + Security Rules هو الطريق الطبيعي.
